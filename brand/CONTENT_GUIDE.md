# 디바스킨 콘텐츠 가이드

디바스킨 본점의 블로그·카드뉴스·릴스·숏폼을 만들 때 따르는 기준이에요.
보기 좋은 버전: https://claude.ai/artifact/CzNdgMP8pxBmT1reK5YscQ

## 대상
- 반복되는 피부 고민(속건조, 성인 트러블, 청소년 여드름, 얼굴·몸 붓기, 등드름, 얼굴윤곽)이 있는 여성
- 청소년 여드름은 학생이 아니라 엄마에게 말한다

## 말투
- 전문적이지만 친근하게, "~해요" 체, 짧은 문장
- 결과 먼저 → 고민 공감 → 과정으로 증명 → 실제 숫자와 솔직한 한계 → 댓글 키워드 CTA
- 숫자는 실제 기록만. 모르면 `[ ]` 빈칸으로 남긴다
- 필요하면 병원(피부과, 치과 턱관절)을 먼저 권한다

## 금지 표현
| 쓰지 않음 | 대신 |
|---|---|
| 치료 | 관리 |
| 완치, 영구 | 정돈, 개선에 도움 |
| 100%, 무조건 | (빼기) |
| 부작용 없음 | 피부 상태 확인 후 진행해요 |
| 얼굴뼈가 작아져요 | 근육 긴장과 붓기가 달라져요 |
| 피부과보다 나아요 | (빼기) |

- 전후 사진은 촬영·게시 동의서가 있는 것만. 미성년자는 보호자 서면 동의 + 얼굴 식별 불가

## 콘텐츠 4기둥
| 기둥 | 비율 | 예시 |
|---|---|---|
| 고민 해설 | 35% | 수분크림 발라도 당기는 이유 |
| 관리 과정과 전후 | 25% | 같은 날 찍은 붓기·윤곽 전후 |
| 홈케어와 셀프체크 | 25% | 체크리스트, 5분 루틴 카드뉴스 |
| 원장의 하루 | 15% | 상담, 준비, 샵 일상 |

## 댓글 키워드
속건조 → 셀프체크 7문항 / 턱 → 트러블 기록표 / 세안 → 학생 세안 가이드 /
붓기 → 5분 순환 루틴 영상 / 등 → 등드름 체크리스트 / 윤곽 → 꽉 무는 습관 셀프체크

## 색 (딥디바 랜딩페이지 기준, 매장 로고 색 확인 전 제안)
- 네이비 `#0D1B35` 제목·진한 배경
- 디바 블루 `#2B5EA7` 포인트
- 라이트 블루 `#5B8DD9`, 페일 블루 `#D6E4FF` 보조
- 크림 `#F0EDE8`, 오프화이트 `#F8F8F6` 배경
- 금지: 보라·핑크 그라데이션, 형광색, 한 장에 포인트 색 두 개 이상. 주제별로 색을 바꾸지 않는다

## 글꼴
- 제목: Noto Serif KR Bold / 본문·자막: Noto Sans KR / 영문 로고: Cormorant Garamond

## 규격
- 카드뉴스 1080×1350, 6장 (표지 → 원인 → 체크·루틴 → 결과·팁 → 생활 습관 → 저장 유도 + 댓글 키워드)
- 모션 릴스 1080×1920, 15초, 글자는 화면 가운데(인스타 UI 피하기)
- 숏폼 1080×1920, 60초 안팎, 위 다섯 단계 구조
