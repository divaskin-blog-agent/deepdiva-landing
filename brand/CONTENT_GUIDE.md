# 디바스킨 콘텐츠 가이드

인스타그램: @diva_skin_official_

디바스킨 본점의 블로그·카드뉴스·릴스·숏폼을 만들 때 따르는 기준이에요.
보기 좋은 버전: https://claude.ai/artifact/CzNdgMP8pxBmT1reK5YscQ

## 대상
- 반복되는 피부 고민(속건조, 성인 트러블, 청소년 여드름, 얼굴·몸 붓기, 등드름, 얼굴윤곽)이 있는 여성
- 청소년 여드름은 학생이 아니라 엄마에게 말한다

## 말투
- 전문적이지만 친근하게, "~해요" 체, 짧은 문장
- 결과 먼저 → 고민 공감 → 과정으로 증명 → 실제 숫자와 솔직한 한계 → 댓글 키워드 CTA
- 숫자는 실제 기록만. 모르면 `[ ]` 빈칸으로 남긴다
- 필요하면 병원(피부과, 치과 턱관절)을 먼저 권한다

## 금지 표현
| 쓰지 않음 | 대신 |
|---|---|
| 치료 | 관리 |
| 완치, 영구 | 정돈, 개선에 도움 |
| 100%, 무조건 | (빼기) |
| 부작용 없음 | 피부 상태 확인 후 진행해요 |
| 얼굴뼈가 작아져요 | 근육 긴장과 붓기가 달라져요 |
| 피부과보다 나아요 | (빼기) |

- 전후 사진은 촬영·게시 동의서가 있는 것만. 미성년자는 보호자 서면 동의 + 얼굴 식별 불가

## 분위기
- 모던, 경쾌한, 판타지한, 행복한, 자유로운, 높은
- 아쿠아 = 수분, 화이트 = 피부, 골드 = 빛. 흰 여백 넉넉히, 아쿠아 물방울과 금색 반짝임

## 콘텐츠 4기둥 (반응 좋았던 주제 반영)
| 기둥 | 비율 | 예시 |
|---|---|---|
| 셀프관리 루틴 ★ | 30% | 윤곽 셀프관리, 붓기 5분 루틴, 셀프체크 |
| 원장과 고객 이야기 ★ | 25% | 관리 중 나눈 연애 이야기, 고민 상담, 샵의 하루 |
| 고민 해설 | 25% | 수분크림 발라도 당기는 이유 |
| 관리 과정과 전후 | 20% | 같은 날 찍은 붓기·윤곽 전후 |

- 바이럴 따라하기는 형식: 유행 음원·밈·챌린지 형식에 디바스킨 내용을 얹는다
- 연애 이야기: 고객을 알아볼 수 있는 정보 빼기, 실제 대화는 먼저 동의 구하기, 각색했으면 밝히기

## 댓글 키워드
윤곽 → 윤곽 셀프관리 루틴·꽉 무는 습관 체크 / 붓기 → 5분 순환 루틴 영상 / 속건조 → 셀프체크 7문항 /
턱 → 트러블 기록표 / 등 → 등드름 체크리스트 / 세안 → 학생 세안 가이드

## 색
- 화이트 `#FFFFFF` 기본 배경 (피부)
- 아쿠아 `#91D3E8` (R145 G211 B232), 민트 아쿠아 `#8ACECF` 면·물방울 (수분)
- 딥 아쿠아 `#0081B2` 글자 강조·버튼·번호
- 골드 `#FFEB00` (R255 G235 B0) 반짝임·형광펜·CTA 바탕에만 (빛). 골드 위 글자는 잉크색
- 잉크 `#0D2B3A` 본문 글자 (제안)
- 흰 바탕 위 글자로 아쿠아·골드를 쓰지 않는다 (가독성)
- 캠페인 컬러(여름, 크리스마스, 연 1회 행사만): 그린(코드 미정), 라이트 블루 `#0081B2`
- 금지: 보라·핑크 그라데이션, 어두운 배경 위주, 한 장에 강조색 세 개 이상, 주제별 색 바꾸기
